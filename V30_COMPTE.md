# V30 — Menu Compte

Le clic sur le pseudo ouvre maintenant un menu Compte avec :
- Changer l’email avec vérification de la nouvelle adresse Firebase
- Changer le mot de passe
- Réinitialisation par email si Firebase demande une reconnexion récente
- Langue FR / EN / TR
- Vérification du compte
- Déconnexion

Les opérations d’authentification passent par Firebase Authentication. Ne pas considérer les réglages frontend comme une sécurité backend.
